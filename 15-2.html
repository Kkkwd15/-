JavaScript程序结构：条件与循环

孙宁

用条件语句做判断、用循环语句重复执行，是 JavaScript 最基本的两种程序结构。下面每个示例都给出代码和实际运行结果。

一、条件语句

1. if / else if / else —— 按分数判断等级

let score = 86;
let grade;

if (score >= 90) {
    grade = "优秀";
} else if (score >= 60) {
    grade = "及格";
} else {
    grade = "不及格";
}

2. switch —— 按数字输出星期几

let day = 3;
let week;

switch (day) {
    case 1: week = "星期一"; break;
    case 2: week = "星期二"; break;
    case 3: week = "星期三"; break;
    case 4: week = "星期四"; break;
    case 5: week = "星期五"; break;
    default: week = "周末";
}

二、循环语句

3. for 循环 —— 求 1 到 100 的和

let sum = 0;

for (let i = 1; i <= 100; i++) {
    sum += i;
}

4. while 循环 —— 统计 1 到 100 中 7 的倍数的个数

let n = 1;
let count = 0;

while (n <= 100) {
    if (n % 7 === 0) {
        count++;
    }
    n++;
}

5. do...while —— 循环体至少执行一次

let i = 10;
let text = "";

do {
    text += i + " ";
    i++;
} while (i < 10);

6. break 与 continue —— 找第一个能同时被 3 和 5 整除的数

let found = 0;

for (let i = 1; i <= 100; i++) {
    if (i % 3 !== 0) {
        continue;            // 不是 3 的倍数就跳过
    }
    if (i % 5 === 0) {
        found = i;
        break;               // 找到后立即结束循环
    }
}

三、条件与循环综合

7. 双重循环 + 条件 —— 输出九九乘法表

let table = "";

for (let i = 1; i <= 9; i++) {
    for (let j = 1; j <= i; j++) {
        table += j + "×" + i + "=" + (i * j) + "  ";
    }
    table += "\n";
}
