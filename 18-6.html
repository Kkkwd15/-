图一：智能客服业务流程图（flowchart）

flowchart TD
    A(["用户发起提问"]) --> B["接入网关 / 会话管理"]
    B --> C{"意图识别 NLU"}
    C -- 闲聊问候 --> D["寒暄应答直接回复"]
    C -- 业务咨询 --> E["知识库检索 RAG"]
    E --> F{"是否命中知识"}
    F -- 是 --> G["组装答案并返回用户"]
    F -- 否 --> H["转接人工坐席"]
    G --> I["记录对话日志"]
    D --> I
    H --> I
    I --> J["Badcase 分析与知识库更新"]
    J -.-> E

图二：智能客服系统数据库 ER 图（erDiagram）

erDiagram
    USER ||--o{ SESSION : initiates
    SESSION ||--|{ MESSAGE : contains
    AGENT ||--o{ SESSION : handles
    CATEGORY ||--|{ KNOWLEDGE : groups
    KNOWLEDGE ||--o{ MESSAGE : answers

    USER {
        int user_id PK "user id"
        string nickname "nickname"
        string email "email"
        datetime created_at "create time"
    }
    SESSION {
        int session_id PK "session id"
        int user_id FK "user id"
        int agent_id FK "agent id"
        string status "open closed"
        datetime started_at "start time"
    }
    MESSAGE {
        int message_id PK "message id"
        int session_id FK "session id"
        string role "user bot agent"
        text content "message body"
        datetime sent_at "send time"
    }
    AGENT {
        int agent_id PK "agent id"
        string name "agent name"
        string group_name "service group"
    }
    CATEGORY {
        int category_id PK "category id"
        string name "category name"
    }
    KNOWLEDGE {
        int knowledge_id PK "knowledge id"
        int category_id FK "category id"
        string question "standard question"
        text answer "standard answer"
        float score "hit score"
    }
