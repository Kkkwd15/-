功能与实现说明

主要功能

  • 顶部品牌导航与全屏首屏视觉，Canvas 星尘/连线动画
  • 房源、订单、营收等关键指标卡片与趋势图表展示
  • 服务健康状态探针：展示后端在线/离线与接口耗时
  • 响应式布局，适配桌面与移动端浏览

技术实现

  • 原生 JavaScript + Canvas 绘制图表与背景动画
  • fetch GET /api/health 检测服务状态，统一 JSON 响应解析
  • 指标为课程演示数据，由前端本地渲染，不依赖第三方图表库
  • 控制台输出请求日志，便于课堂演示报文格式

主要后台接口

GET /api/healthGET /api/site-info

运行方式

cd backend && node app.js　→　http://localhost:8016/sun_hub.html

注意：健康探针需要本地后端；静态托管下状态会显示离线，但页面视觉仍可查看。新版首页只链接本说明页。
