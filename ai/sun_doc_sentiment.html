评论情感分析

把住客评论转成可统计的情感结论：支持 Excel 批量导入、图片文字识别（OCR）、语音转写与单条文本分类，任务列表展示每条评论的正面/中性/负面判定与置信度。

页面截图

真实运行截图（本地后端 8016 端口）· 点击图片可放大查看

功能与实现说明

主要功能

  • Excel（.xlsx）批量上传，自动解析评论列并逐条分类
  • 图片上传 OCR 识别图中评论文字，语音口述转文字后分类
  • 单条文本即时分析，输出情感标签与置信度
  • 任务列表与详情、情感分布统计、结果表格与导出辅助

技术实现

  • 原生 JS + fetch 上传 FormData，服务端 multer 接收文件
  • Excel 解析、图像文字识别与语音转写在服务端/本地工具链完成
  • 情感判定采用词典/规则打分（课程演示用），结果落 MySQL
  • 统一 JSON 响应，前端对不同输入方式做容错提示

主要后台接口

GET /api/sentiment/tasksPOST /api/sentiment/upload POST /api/sentiment/ocrPOST /api/sentiment/text GET /api/sentiment/tasks/:id

运行方式

cd backend && node app.js　→　http://localhost:8016/sun_sentiment.html

注意：Excel / 图片 / 语音解析均需本地后端与 MySQL；静态托管下仅能看到页面框架，故新版首页链接到本说明页。
